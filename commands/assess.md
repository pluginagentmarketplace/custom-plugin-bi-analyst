# /assess - Evaluate Your Knowledge and Skills

Assess your current knowledge across different development domains, identify learning gaps, and get personalized recommendations for improvement.

## Usage

```
/assess
→ Choose assessment type
→ Answer skill-based questions
→ View your proficiency levels
→ Get personalized learning recommendations
```

## Assessment Types

### 1. Quick Assessment (10 minutes)
- 20 questions across multiple domains
- Quick gauge of overall knowledge level
- Identifies strongest and weakest areas
- Generates summary report

### 2. Role-Based Assessment (20 minutes)
- Comprehensive evaluation for a specific role
- 50+ targeted questions
- Detailed proficiency breakdown
- Personalized learning path recommendations

### 3. Skill Assessment (15 minutes)
- Deep dive into specific technical skill
- 30+ focused questions
- Proficiency from beginner to expert
- Resource recommendations

### 4. Full Assessment (60 minutes)
- Complete evaluation across all domains
- 200+ comprehensive questions
- Detailed skill matrix
- Career guidance report

## Sample Questions

### Beginner Level
```
Q: What does the 'const' keyword do in JavaScript?
A) Declares a variable that can be reassigned
B) Declares a variable that cannot be reassigned
C) Declares a global variable
D) Declares a function variable

Correct: B) Declares a variable that cannot be reassigned
```

### Intermediate Level
```
Q: In a React component, what's the difference between
   state and props?
A) State is local to a component, props are passed from parent
B) Props are local to a component, state is passed from parent
C) They are the same thing
D) State is for classes, props for functions

Correct: A) State is local to a component, props are passed from parent
```

### Advanced Level

   system with millions of users and frequent updates.

## Tips for Assessment Success

1. **Be Honest**: Choose answer you truly believe
2. **Take Your Time**: Don't rush, think through questions
3. **Skip If Unsure**: Mark for later review
4. **Review Results**: Analyze weak areas carefully
5. **Act on Feedback**: Use recommendations immediately
6. **Retake Periodically**: Track progress every 4-6 weeks

## Assessment FAQ

**Q: How accurate is this assessment?**
A: Based on 1000+ real interview questions, validated by industry experts. ~85% correlation with actual skill level.

**Q: How long does results remain valid?**
A: 3 months recommended. Tech field moves fast, retake quarterly.

**Q: Can I retake the assessment?**
A: Yes, unlimited. Take it weekly to track progress if desired.

**Q: Will results be saved?**
A: Yes, with full history showing your improvement trajectory.

**Q: What if I disagree with results?**
A: Detailed feedback on each question shows reasoning. You can request a manual review.
